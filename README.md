# FreshTrack — Grocery Expiration Tracker

## Project Description

FreshTrack is a Python application designed to help users organize their groceries and keep track of expiration dates. The goal is to reduce food waste by making it easier to identify which groceries need to be used before they expire.

This project is being developed for my Data Structures final project.

## Planned Features

- Add grocery items with names, quantities, and expiration dates.
- Search for grocery items in the inventory.
- View groceries that are approaching their expiration dates.
- Sort grocery items alphabetically.
- Remove groceries from the inventory.
- Use a graphical user interface (GUI) for easier interaction.

## Data Structures and Algorithms

FreshTrack will implement the following:

**Hash Table:** Stores grocery items and allows users to search for them efficiently.

**Min-Heap:** Organizes grocery items by expiration date so items expiring soonest can be identified quickly.

**Insertion Sort:** Sorts grocery items alphabetically by name.

These data structures and the sorting algorithm will be implemented in Python as part of the project.
